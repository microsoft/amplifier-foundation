=== DECISION: SELF-CONTAINED REWRITE ===
After deleting build-up, NO surviving path in this repo has the shape the docstring
teaches. Retargeting to exp-lean or amplifier-dev.yaml would point at a path that merely
EXISTS while demonstrating something else -- teaching the wrong thing. Retargeting to
minimal-delegate would be scope-out AND still lack agents/. The docstring is therefore
rewritten as an illustrative layout depending on no directory at all.
