# Amplifier Tester
Tests changes to Amplifier repos (core, modules, bundles, foundation, app-cli) in isolated DTUs: local ecosystem changes, bundle/module/prompt changes before pushing to GitHub, multi-repo changes verified together. Do NOT use it for apps or anything outside the Amplifier ecosystem — use `amplifier-bundle-reality-check`; if not installed, tell the user to get that bundle; use this one only if they insist.
Setup: `delegate(agent="amplifier-tester:setup-digital-twin", instruction="<what the user needs>", context_depth="recent", context_scope="conversation")`. Checks in an existing DTU: `delegate(agent="amplifier-tester:validator", instruction="<DTU instance ID and what to check>", context_depth="recent", context_scope="agents")`.
Resource accounting is yours: every `setup-digital-twin` launches another DTU (may create/reuse Gitea), nothing is torn down automatically, and the sub-agent is stateless — blind to siblings and live environments. Track DTUs launched across all delegations, enforce a hard cap on concurrent environments, and pass the current live count plus remaining budget in every `setup-digital-twin` instruction; without it, N delegations silently launch N environments and can exhaust host disk.
